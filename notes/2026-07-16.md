## Understanding HTTP History vs Intercept

One important concept learned today was the distinction between Burp's different modules.

### HTTP History

- Stores requests that have already been sent.
- Used for reviewing captured traffic.
- Requests are not directly editable.

### Intercept

- Stops requests before they reach the server.
- Allows modification of headers, parameters, and payloads.
- Requests can then be forwarded manually.

Understanding this workflow clarified why previously captured requests could not be modified directly from HTTP History.
